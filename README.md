# 🌸 Desktop Waifu AI - DeepSeek V4-1-Flash (Kie.ai)

Uma assistente waifu 3D tsundere que fica **flutuando sobreposta na sua área de trabalho**, com **legendas amarelas estilo anime com bordas brancas**, modo mudo, histórico com janela de contexto e personalidade **tsundere autêntica**.

---

## 💢 Personalidade Tsundere Ativada

A Kie-chan agora tem a verdadeira personalidade tsundere configurada:
- **Negação constante**: *"Não é como se eu gostasse de você ou algo assim..."*
- **Reações envergonhadas**: Gagueja, fica vermelha e solta *"b-baka!"* ou *"idiota"* quando elogiada.
- **Ações expressivas em itálico**: `*olha para o lado com o rosto vermelho*`, `*cruza os braços*`, `*bate o pé*`.
- **Janela de Contexto**: Ela se lembra de conversas anteriores durante o diálogo (até 20 turnos de memória persistente).

---

## 📜 Histórico de Diálogo & Memória

- Pressione a tecla **`H`** (ou clique no ícone **`📜`** no topo ou na barra de comando).
- Abre uma janela translúcida com todo o histórico de falas da sessão.
- Possui o botão **🗑️ Limpar Memória** caso queira reiniciar o contexto da conversa.

---

## ⏱️ Legendas Calibradas (Velocidade Confortável)

- As legendas agora não somem instantaneamente:
  - Cada frase faz uma pausa de **quase 2 segundos** após a leitura para você ler com calma.
  - Ao terminar toda a resposta, a legenda fica visível por **4 segundos** antes de desaparecer suavemente.
  - Destaque palavra por palavra com ritmo natural.
  - Ajuste fino da velocidade disponível nas Configurações (⚙️ ➔ *Legenda & Áudio*).

---

## ⌨️ Atalhos Rápidos

| Tecla / Ação | O que faz |
| :--- | :--- |
| **`/`** | Abre o campo moderno para digitar sua mensagem |
| **`Enter`** | Envia a mensagem para a Kie-chan |
| **`Esc`** | Fecha a barra de mensagem, histórico ou configurações |
| **`H`** | Abre o **Histórico de Conversas** e janela de contexto |
| **`M`** | Liga / Desliga o **Modo Mudo** (silencia a voz) |
| **`Alt + Arrastar`** | Move a waifu pela tela do PC |
| **`Scroll do Mouse`** | Aumenta ou diminui o tamanho dela |
| **`⚙️`** | Abre as configurações |
